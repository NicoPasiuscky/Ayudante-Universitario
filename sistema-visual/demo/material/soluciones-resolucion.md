# Soluciones: resolución completa

::: subtitulo
Materia de ejemplo, parcial de demostración. Hoja aparte de los enunciados: resolvé primero y usá esta hoja solo para comparar.
:::

::: {.ejercicio n=1}
a. **Variación neta.** Es la diferencia entre el valor final y el inicial:

   $$\Delta y = y_{f} - y_{i} = 56{,}0\ \text{°C} - 20{,}0\ \text{°C}$$

   ::: resultado
   $\Delta y = 36{,}0\ \text{°C}$
   :::

b. **Tasa de variación promedio.**

   $$\bar{r} = \dfrac{\Delta y}{\Delta t} = \dfrac{36{,}0\ \text{°C}}{12{,}0\ \text{min}}$$

   ::: resultado
   $\bar{r} = 3{,}00\ \frac{\text{°C}}{\text{min}}$
   :::

c. **Tiempo hasta 80,0 °C.** Hay que variar $60{,}0\ \text{°C}$ a esa misma tasa:

   $$t = \dfrac{\Delta y}{\bar{r}} = \dfrac{80{,}0\ \text{°C} - 20{,}0\ \text{°C}}{3{,}00\ \frac{\text{°C}}{\text{min}}}$$

   ::: resultado
   $t = 20{,}0\ \text{min}$
   :::

::: supuesto
La tasa se mantiene constante durante todo el calentamiento.
:::
:::

::: {.ejercicio n=2}
a. **Variación neta de volumen.** Se suma lo que entra y se resta lo que sale:

   $$\Delta V = 40{,}0\ \text{L} - 15{,}0\ \text{L}$$

   ::: resultado
   $\Delta V = 25{,}0\ \text{L}$
   :::

b. **Tasa de variación promedio.**

   $$\bar{r} = \dfrac{\Delta V}{\Delta t} = \dfrac{25{,}0\ \text{L}}{13{,}0\ \text{min}}$$

   ::: resultado
   $\bar{r} = 1{,}92\ \frac{\text{L}}{\text{min}}$
   :::

c. **Tasa de variación total.** Se suman los cambios en valor absoluto:

   $$\bar{r}_{T} = \dfrac{\left|40{,}0\ \text{L}\right| + \left|-15{,}0\ \text{L}\right|}{13{,}0\ \text{min}} = \dfrac{55{,}0\ \text{L}}{13{,}0\ \text{min}}$$

   ::: resultado
   $\bar{r}_{T} = 4{,}23\ \frac{\text{L}}{\text{min}}$
   :::

   Comprobación: es mayor que el módulo de la tasa promedio, como corresponde cuando el volumen sube y baja.
:::

::: {.ejercicio n=3}
Se leen de la gráfica los puntos $P = (2{,}00\ \text{min};\ 14{,}0\ \text{L})$ y $Q = (10{,}0\ \text{min};\ 46{,}0\ \text{L})$.

   $$\bar{r} = \dfrac{V_{Q} - V_{P}}{t_{Q} - t_{P}} = \dfrac{46{,}0\ \text{L} - 14{,}0\ \text{L}}{10{,}0\ \text{min} - 2{,}00\ \text{min}}$$

   ::: resultado
   $\bar{r} = 4{,}00\ \frac{\text{L}}{\text{min}}$
   :::

Como la gráfica es una recta, la tasa es la misma en todo el intervalo y el volumen a los 6,00 min se obtiene desde P:

   $$V = V_{P} + \bar{r}\,(t - t_{P}) = 14{,}0\ \text{L} + 4{,}00\ \frac{\text{L}}{\text{min}} \cdot 4{,}00\ \text{min}$$

   ::: resultado
   $V = 30{,}0\ \text{L}$
   :::

:::
:::
